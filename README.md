# Objective
The objective of Week 2 is to understand the basic machine learning workflow and train a Linear Regression model using Python and Scikit-learn.

# Dataset
A simple dataset containing Study Hours and Marks was created.

- Feature: Study Hours
- Target: Marks

# Steps Performed

1. Created a dataset containing study hours and marks.
2. Converted the dataset into a Pandas DataFrame.
3. Selected Study Hours as the feature (X).
4. Selected Marks as the target (y).
5. Split the dataset into training and testing sets using `train_test_split()`.
6. Created a Linear Regression model using Scikit-learn.
7. Trained the model using `model.fit()`.
8. Generated predictions using `model.predict()`.
9. Evaluated the model using MAE, MSE, RMSE, and R² Score.

# Model Evaluation

The model produced the following results:

- MAE: 1.4655
- MSE: 3.7102
- RMSE: 1.9262
- R² Score: 0.9941
